# Machine Workload Transfer & Tooling Changeover Protocol

## 1. Overview
When transferring production operations from an unavailable primary machine to an alternative candidate machine, strict changeover protocols must be observed.

## 2. Changeover Protocol
1. **Fixture Compatibility:** Confirm target machine mounting plate aligns with workpiece tooling.
2. **Program Transfer:** Load CAD/CAM NC code corresponding to the transferred model.
3. **Dry Run Verification:** Execute 1 complete motion cycle without payload to verify envelope clearance.
4. **Setup Penalty:** Allow 30–60 minutes for changeover setup depending on operation type.
