# Production SOP: High-Priority Delivery Order Expediting

## 1. Definition
High-priority orders represent committed key OEM delivery contracts with strict SLA penalties.

## 2. Mitigation Rules
- If a machine failure impacts 1 or more HIGH priority orders, overall factory Delivery Risk is automatically escalated to `HIGH`.
- Recovery plans must explicitly prioritize capacity recovery for HIGH priority orders before LOW/MEDIUM priority orders.
