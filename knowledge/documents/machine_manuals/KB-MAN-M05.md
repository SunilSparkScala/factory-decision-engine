# M05 Robotic Welding Unit 2 — Technical Specifications

## 1. Overview
M05 is an automated 6-axis robotic articulation welding cell located at Station A2 on Line A (Sedan Line). It performs structural chassis spot welding for Model-S and Model-E vehicles.

## 2. Technical Capabilities
- **Cycle Time:** 120.0 seconds per sub-assembly
- **Rated Capacity:** 30.0 units/hour
- **Welding Wire Feed:** MAT_03 (0.8mm MIG wire)
- **Positioning Accuracy:** ±0.05 mm

## 3. Substitution & Transfer Capability
- M05 is fully compatible with Line A Station A2 operations (M04, M06).
- Can accept overflow production from Line B Station B2 (Welding) provided fixture adapters are installed.

## 4. Operational Restrictions
- Electrode tip dress required every 500 spot welds.
- If shielding gas pressure falls below 4.5 bar, automatic weld abort is triggered.
