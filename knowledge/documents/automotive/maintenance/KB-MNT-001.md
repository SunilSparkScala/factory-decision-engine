# Standard Operating Procedure: Post-Downtime Machine Restart

## 1. Purpose
To specify mandatory safety and verification steps prior to restarting any manufacturing machine following unplanned downtime or corrective maintenance.

## 2. Procedure Steps
1. **Physical Clearance:** Verify all technicians, tools, and maintenance equipment are clear of the cell boundary.
2. **Safety Circuit Reset:** Reset physical E-stop switches and light curtains.
3. **Dry Run Cycle:** Execute 1 empty cycle (without workpiece) to verify pneumatic, hydraulic, and robotic positioning accuracy.
4. **First Piece Verification:** Run 1 test component. Inspect dimensions against tolerance specifications.
5. **Production Release:** Formal sign-off by Shift Supervisor before restoring automatic production mode.
