# M05 Pick-and-Place Unit 2 — Technical Specifications

## 1. Overview
M05 is a high-speed pick-and-place machine located at Station A2 on Line A (Router Line). It places components on NW-Router and NW-Hub boards.

## 2. Technical Capabilities
- **Cycle Time:** 120.0 seconds per panel
- **Rated Capacity:** 30.0 panels/hour
- **Placement Accuracy:** ±0.03 mm

## 3. Substitution & Transfer Capability
- M05 is fully compatible with Line A Station A2 operations (M04, M06).
- Can accept overflow production from Line B Station B2 (Pick-and-place) provided the feeder bank is re-kitted.

## 4. Operational Restrictions
- Nozzle cleaning required every 20,000 placements.
- If vacuum pressure falls below threshold, automatic placement abort is triggered.
