# Standard Operating Procedure: Post-Downtime Machine Restart

## 1. Purpose
To specify mandatory safety and verification steps before restarting any production machine after unplanned downtime or corrective maintenance.

## 2. Procedure Steps
1. **Physical Clearance:** Verify all technicians and tools are clear of the machine.
2. **Safety Circuit Reset:** Reset E-stop switches and safety interlocks.
3. **Dry Run Cycle:** Run 1 empty cycle to verify gantry, conveyor and vision alignment.
4. **First Board Verification:** Run 1 test board and inspect it against specification.
5. **Production Release:** Formal sign-off by the Shift Supervisor before returning to automatic mode.
