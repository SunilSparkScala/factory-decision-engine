# Machine Workload Transfer & Changeover Protocol

## 1. Overview
When production moves from an unavailable machine to an alternative machine, strict changeover steps must be followed.

## 2. Changeover Protocol
1. **Feeder & Stencil Readiness:** Confirm the target machine has the correct feeder setup or stencil for the board.
2. **Program Transfer:** Load the placement or print program for the transferred product.
3. **Dry Run Verification:** Run 1 cycle without a board to verify motion and vision alignment.
4. **Paste Handling:** Clean stencils and condition solder paste to room temperature before printing.
5. **Setup Penalty:** Allow 30–60 minutes for changeover depending on operation type.
